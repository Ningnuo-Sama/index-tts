## 2. 本地源码改动（唯一一处，15 增 3 删）

`indextts/infer_v2_5.py`：让 w2v-bert 特征提取器可以独立放 CPU，由环境变量 `INDEXTTS_SEMANTIC_DEVICE=cpu` 触发；不设变量时行为与上游完全一致。

+        self.semantic_std = torch.sqrt(stat_mean_var["var"]).to(self.semantic_device)

## 3. 脚本职责（全部在 `tools\`）

| 脚本 | 作用 |
| --- | --- |
| `start_webui.ps1` | 起 Gradio WebUI（7860）。默认先 `ollama_mode -Mode partial` + `--semantic-cpu` |
| `start_api.ps1` | 起独立 FastAPI 服务（7861，OpenAI 兼容 `/v1/audio/speech`） |
| `run_webui.py` | WebUI 启动器：进程内修 `NO_PROXY`（去 `[::1]`）、直连、`--semantic-cpu` → 环境变量 |
| `tts_session.ps1` | **临时出片会话**：切显存 → 出片 → 还原 Ollama 原状态。默认走 `batch_infer.py`（**不起 WebUI**，单条 77 秒）；`-Preset` 读 WebUI 配方；`-ViaWebUI` 才起 Gradio（112 秒） |
| `tts_client.py` | 调 WebUI 的 gradio API 生成（复用已加载模型，不额外加载） |
| `batch_infer.py` | 独立进程批量合成（自己加载模型，出片主路径）。`--preset <名字>` 直接复用 WebUI 保存的配方，`--list-presets` 列出 |
| `script_to_voice.py` | 按情绪分段出片：稿子每行带 `[情绪]` 标签（或 JSONL 给 8 维向量/强度/语速），逐句生成后拼成一条完整音频。`--auto-emo` 让模型自判情绪（需 QwenEmotion） |
| `ollama_mode.ps1` | 切 Ollama：`status`/`partial`(24 层)/`gpu`(全量)/`cpu`/`offload`，带 runner 卡死自愈 |
| `free_vram.ps1` | 仅把 Ollama 权重移出显存（下次请求 0.32 秒回载） |
| `baseline_check.ps1` | 只读输出本文件的全部可核验事实（`-Json` 给机器读） |

## 4. 实测基线（RTX 4070，bf16，无 cuda_kernel/accel/deepspeed）

| 配置 | TTS 一句 | 向量检索 | 显存 |
| --- | --- | --- | --- |

## 5. 已解决的问题（评审时容易复发的点）

1. **gradio 起不来**：`httpx.InvalidURL: Invalid port ':1]'`。系统 `NO_PROXY` 含 `[::1]`，httpx 0.28 把方括号 IPv6 当主机+端口。修法在 Python 进程内改 `NO_PROXY`（本机 pwsh 改 `$env:` 覆盖不到子进程）。
2. **显存挤爆**：dwm 2 GB + Ollama 全量 3.9 GB + IndexTTS 6.3 GB 超 12 GB，WDDM 分页后 token 速率掉到 0.03 it/s（一句 255~380 秒）。解法是两边各砍一刀（w2v 搬 CPU + Ollama 24 层）。
3. **Ollama runner 卡死**：从 CPU 态往 GPU 重载时请求不返回。杀 `llama-server` 后 3.7 秒重建正常；`ollama_mode.ps1` 已内置 120 秒超时自愈。
4. **gradio API 参数**：`/gen_single` 26 个位置参数，参考音频必须先 `POST /gradio_api/upload`，传本地路径会 `InvalidPathError`。

## 7. 复现命令

```powershell
cd D:\GitHub\index-tts
pwsh -File tools\baseline_check.ps1            # 打印本节所有事实；-Json 给机器读
pwsh -File tools\tts_session.ps1 -Text "验收一句话" -Out scratch\check.wav
pwsh -File tools\tts_session.ps1 -Script 稿子.txt -OutDir outputs\job -Voice voice_01
pwsh -File tools\tts_session.ps1 -Script 稿子.txt -OutDir outputs\job -Preset 老江口播  # 用界面调好的配方
.\.venv\Scripts\python.exe tools\batch_infer.py --list-presets                     # 看有哪些配方
```

配方存 `outputs\presets\<名字>\{preset.json, prompt.wav, emo_ref.wav}`，由 WebUI「预设管理」页保存，无头脚本读同一份；不含语言与语速，这两项每次单独给。

出片会话结束会自动还原成「Ollama 全量 GPU、WebUI 关闭」的日常基线。
